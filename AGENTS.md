# Рабочий проект Igarka

Это единственная рабочая копия Игарского портала и репозиторий
https://github.com/svmalyshev/Igarka. Ветка: main.

- Изменения Игарского проекта выполняйте здесь. Старый каталог
  `../Igarka_samples_portal` содержит Бирюсу и переходы для прежних закладок.
- Главная страница — `index.html`. Промежуточную страницу выбора регионов
  и файлы Бирюсы в этот репозиторий не добавляйте.
- Сборщик портала — `build_portal.py`; путеводителя — `build_guide.py`.
  Общие сырые данные находятся в родительской папке `2025_Игарка`.
- Полный исходный текст путеводителя сохраняется без сокращений.
- Синхронизацию с GitHub выполняйте только вручную по запросу пользователя
  после значительных изменений: `python3 scripts/sync_github.py`.
  Не запускайте фоновую синхронизацию и не отправляйте изменения автоматически.
- При конфликте локальной и удалённой истории остановитесь и сообщите об этом.
  Не выполняйте force-push, reset --hard или автоматическое разрешение конфликтов.
- Незавершённые изменения во время активной работы не отправляйте.
