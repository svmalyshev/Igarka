# Igarka

Самостоятельный Игарский портал. `index.html` сразу открывает карту
с образцами, фотографиями, геохимией и геохронологией.
Путеводитель: `guide.html`; полная сводка: `guide-full.html`.

Для GitHub загрузите содержимое этой папки в корень репозитория `Igarka`.
В Settings → Pages выберите Deploy from a branch → main → /(root).
Файл `.nojekyll` и все папки с фотографиями и тайлами должны быть загружены.
Спутниковые снимки Google требуют подключения к интернету.

Бирюса — отдельный проект и в эту сборку не входит.
