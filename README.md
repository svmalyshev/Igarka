# Igarka

Рабочий репозиторий Игарского портала. `index.html` сразу открывает карту
с образцами, фотографиями, геохимией и геохронологией.
Путеводитель: `guide.html`; полная сводка: `guide-full.html`.

Репозиторий: https://github.com/svmalyshev/Igarka

Публикация: Settings → Pages → Deploy from a branch → main → /(root).
Файл `.nojekyll` и папки с фотографиями и тайлами входят в репозиторий.
Спутниковые снимки Google требуют подключения к интернету.

Бирюса — отдельный проект и в эту сборку не входит.

## Работа с проектом

Все изменения Игарского портала выполняются в этой папке.
`build_portal.py` собирает главную страницу, фотографии, карты и путеводитель.
Сырые каталоги и лабораторные файлы остаются в родительской папке `2025_Игарка`;
пути к литературным аналитическим наборам указаны в сборщиках.

На текущем компьютере полная сборка выполняется командой:

```bash
MPLCONFIGDIR=/private/tmp/igarka-mpl /Users/sergeymalyshev/opt/anaconda3/bin/python3 build_portal.py
```

После значительных и проверенных изменений синхронизация выполняется вручную
по запросу пользователя. Автоматической фоновой синхронизации нет:

```bash
python3 scripts/sync_github.py
```

Скрипт получает удалённую историю, создаёт коммит локальных изменений и выполняет
обычный push. Чужие изменения загружаются только fast-forward и только при чистой
рабочей копии. При конфликте или отсутствии авторизации скрипт останавливается.
